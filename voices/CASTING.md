## 収録・実装ルール

- 音声は配役ごとに**異なる声のID**を使用し、速度・音程加工だけで7役にしない。
- 台詞ごとに短い息継ぎ、自然な間を入れ、強い感情は決戦時の一部に限定する。
- 書き出しは、日本語音声のモノラルまたはステレオ MP3/OGG、48 kHz推奨。BGMより明確に聞こえる音量に統一。
- `voices/manifest.json` の `previews` に試聴ファイル、`clips` に**役名＋台詞全文と対応する音声ファイル**を登録する。実際の通信イベントは同じ台詞のときだけ再生する。
- 端末の `speechSynthesis` は使用しない。音声がない台詞は字幕だけとする。
- ファイル名は英数字とアンダースコアを使用。公開サイトの音声は `voices/<role>/<filename>.mp3` 等を同一ドメインから配信し、APIキーを公開しない。
- タイトル画面の7役試聴と発艦イベントを実機で確認し、男性／女性の声が重複していないか聴感試験を行う。

## manifest 書式

```json
{
  "version": 1,
  "previews": {
    "captain": "voices/captain/preview.mp3",
    "control": "voices/control/preview.mp3"
  },
  "clips": [
    {
      "role": "captain",
      "text": "白雪、発艦を許可する。必ず帰ってこい。",
      "src": "voices/captain/preview.mp3"
    }
  ]
}
```

音声生成サービスの接続とキャスティングの承認後、各役の収録データを生成してここへ追加する。
